# Process

This project was not completed in one go. It developed through a process of experimentation, reflection, and continuous adjustment. I explored different ways to present the data, not only in terms of visual style and aesthetics, but also in how people could experience the results.

The project gradually evolved from a 2D visualisation to a 3D representation, and eventually into an interactive website. Each stage gave me a chance to rethink the presentation, explore new possibilities, and learn the tools and techniques needed to take the project further. Rather than following a fixed plan from the beginning, I learned by trying things out, identifying what could be improved, and making changes along the way.

This iterative process was an important part of the project. It helped me develop both my technical skills and my understanding of how data can be communicated through visual and interactive experiences.

## Tools

- Python:** Used to process astronomical data and create the visualisations.
- uv:** Used to run the Python scripts and manage the project environment.
- Visual Studio Code:** Used to edit and work on the project files.
- GitHub:** Used to store the project files and track changes.
- GitHub Pages:** Used to publish the interactive visualisation online.
- ChatGPT:** Used as an AI assistant to help understand code, troubleshoot problems, and improve the project documentation. I reviewed the suggestions and checked them against my project before applying them.

## Kept

I kept the suggestion to publish the interactive visualisation using GitHub Pages. This made the project easier to access and allowed people to explore the visualisation directly in a web browser, without having to run the Python code themselves.

## Rejected

I chose not to add unnecessary tools or complexity when the existing workflow was sufficient. I wanted to keep the code manageable and focus on improving the visualisation itself. This helped me maintain a clear workflow while continuing to develop the project.
